# Security

Report vulnerabilities in Networth Corp repositories to **careers@networth-corp.com** with the subject `GitHub security`.

Do not file public issues for security reports.

## Access model

- Write access is limited to Networth Corp staff (`@networth-corp.com`).
- Hiring candidates work on **forks they own**. They never receive write on this organization.
- Private repositories in this org cannot be forked.
- Default organization permission is none.

If you receive a request to grant write access to a personal Gmail / non-company account, refuse it and tell `nitish@networth-corp.com`.
