# Networth Corp

We build **enterprise decision systems** — production-grade data, AI, and cloud infrastructure. Deliverables become operating systems, not prototypes.

This GitHub organization hosts **engineering hiring assignments**. Candidates fork a public repo, implement a real Week-1 artifact, and submit the result. Write access stays with Networth Corp staff.

[Website](https://www.networth-corp.com) · [Careers](https://www.networth-corp.com/careers) · [Contact](mailto:careers@networth-corp.com)

---

## If you are a candidate

1. **Do not request org membership or write access.** Those requests are declined.
2. Fork the assignment repository you were emailed into *your* GitHub account.
3. Implement only the pack you were assigned.
4. Keep your work in the fork. Reply on the email thread with:
   - the fork URL
   - optional deploy URL
   - a short `ARCHITECTURE.md` (≤40 lines)
5. Questions about the brief go back on the email thread — not as issues on the upstream repo.

Staff emails are `@networth-corp.com`. If someone without that domain asks you to push here, it is not us.

---

## If you are Networth Corp staff

- Only `@networth-corp.com` identities get write.
- Default member permission is **none**. Access is granted per-repo via the `staff` team.
- Candidates never become members or outside collaborators.
- Assignment repos stay public so they can be forked. Private repos are internal only and cannot be forked.

---

## What we hire for

AI engineering, data science, data engineering, and adjacent systems roles. The screen is a shippable GitHub artifact with a pinned corpus and a deterministic eval harness — not a take-home essay.
