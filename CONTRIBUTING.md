# Contributing

This organization publishes hiring assignments. It is not an open-source contribution venue.

## Candidates

- Fork the assignment into your own account.
- Do **not** open pull requests against Networth-Corp repositories unless a staff member explicitly asks.
- Do **not** request org membership, write access, or collaborator access.
- Submit by emailing your fork URL on the existing hiring thread.

## Staff

- You must use a verified `@networth-corp.com` GitHub identity.
- Push via the `staff` team. Do not add outside collaborators to assignment repos.
- Prefer a pull request for anything that changes candidate-facing instructions.
